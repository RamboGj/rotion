## ✨ Overview

**Rotion** is a desktop note-taking app inspired by Notion. Create, edit, and organize
rich-text documents in a clean, distraction-free workspace — all stored locally on your
machine. It's a study project that puts a full Electron + React architecture into practice:
a typed IPC layer, a Notion-style block editor, native OS integrations (system tray & global
shortcuts), and server-state management with React Query.

## 🚀 Features

- **📄 Rich-text editor** — a Notion-like writing experience powered by [Tiptap](https://tiptap.dev/), with headings, lists, highlights, and typography shortcuts.
- **🧠 Smart titles** — the first heading of a document automatically becomes its title across the sidebar and breadcrumbs.
- **🗂️ Document management** — create, open, save, and delete documents from a persistent sidebar.
- **💾 Offline-first storage** — everything is saved locally with [`electron-store`](https://github.com/sindresorhus/electron-store); no account or internet required.
- **🔎 Command palette / search** — quickly jump between documents with a [`cmdk`](https://cmdk.paco.me/)-powered search bar.
- **🧭 Table of contents & breadcrumbs** — navigate long documents and see where you are at a glance.
- **⚡ Native integrations** — a system tray menu and a global `Ctrl/Cmd + N` shortcut to spin up a new document from anywhere.
- **🎨 Dark, focused UI** — styled with Tailwind CSS v4 and Radix primitives.

## 🏗️ Architecture

Rotion follows Electron's three-process model, with a fully typed IPC contract shared
between the main and renderer processes:

```
src/
├── main/        # Main process — app lifecycle, windows, tray, shortcuts, IPC handlers, store
├── preload/     # Secure bridge exposing a typed API to the renderer
├── renderer/    # React app — pages, components (Editor, Sidebar, Header, ToC), routes
└── shared/      # IPC channel constants & TypeScript types shared across processes
```

Documents flow through a request/response IPC layer (`FETCH_ALL`, `FETCH`, `CREATE`,
`SAVE`, `DELETE`) defined in `src/shared`, keeping the renderer decoupled from persistence.

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+ and npm

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd rotion

# Install dependencies
npm install
```

### Development

```bash
# Run the app in development mode with hot reload
npm run dev
```

### Build

```bash
# Windows
npm run build:win

# macOS
npm run build:mac

# Linux
npm run build:linux
```

Packaged installers are generated by [electron-builder](https://www.electron.build/).
